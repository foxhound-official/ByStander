# ByStander

**ByStander** - Android-игра в жанре текстового квеста, построенная вокруг интерфейса терминала, интерактивных сюжетных глав, анимаций и атмосферного звукового сопровождения.

Игрок взаимодействует с приложением через командную строку, получает доступ к событиям и может запускать или очищать отдельные главы.

## Возможности

* Терминальный интерфейс
* Интерактивные сюжетные главы
* Управление игрой через команды
* Анимированное главное меню
* Анимации интерфейса
* Звуковые эффекты
* Атмосферный саундтрек
* Экран настроек
* Экран информации о разработчике
* Локальная система сохранений, заложенная в архитектуру приложения
* Портретная ориентация интерфейса

## Игровой процесс

Основное взаимодействие с игрой происходит через имитацию терминала.

В приложении предусмотрены три сюжетные главы:

1. **Booting Up**
2. **First Contact**
3. **Mutual Aid**

Описание глав:

* `Booting Up` - попытаться разобраться в происходящем
* `First Contact` - установить связь и продолжить путь
* `Mutual Aid` - работать вместе для достижения общей цели

На экране глав расположены терминал и поле для ввода команд.

### Доступные команды

```text
help
```

Показывает список доступных команд.

```text
run <event_name>
```

Запускает выбранное событие.

```text
clear <event_name>
```

Очищает сохранение выбранного события.

Пример:

```text
run stage1_booting_up
```

Приложение разбирает введённую команду и выводит сообщение об ошибке, если команда или событие не распознаны.

## Структура приложения

После запуска приложение открывает `MenuActivity`.

Главное меню содержит три основных действия:

* запуск игры
* открытие настроек
* просмотр информации о разработчике

При выборе **Start** открывается `ChaptersActivity`.

При выборе **Config** открывается `ConfigActivity`.

При выборе **Info** открывается `InfoActivity`.

## Основные компоненты

### MenuActivity

`MenuActivity` является главным экраном приложения.

Отвечает за:

* отображение главного меню
* переход между экранами
* воспроизведение звука меню
* запуск анимаций
* появление названия приложения
* анимацию значка глаза

Главное меню использует последовательность анимаций для появления названия приложения, информации о разработчике и элементов управления.

### ChaptersActivity

`ChaptersActivity` содержит основной интерфейс текстового квеста.

Компонент отвечает за:

* отображение сюжетных глав
* терминал
* ввод команд
* обработку команд
* проверку корректности команд
* прокрутку терминала
* визуальную реакцию на выполнение команд
* звуковое сопровождение выбора главы

Команда разбивается на отдельные элементы по пробелу.

Первый элемент определяет действие:

```text
run
clear
help
```

Второй элемент определяет событие.

### ConfigActivity

`ConfigActivity` представляет экран настроек приложения.

На текущем этапе это отдельный экран, подготовленный для размещения настроек приложения.

### InfoActivity

`InfoActivity` содержит информацию о разработчике.

Экран предоставляет:

* кнопку возврата
* переход на GitHub
* возможность отправить письмо разработчику

GitHub-кнопка открывает профиль:

```text
https://github.com/Crosska
```

Для отправки письма используется стандартный Android `Intent`, который передаёт адрес электронной почты установленному почтовому клиенту.

### AmbientMediaPlayer

`AmbientMediaPlayer` является Android `Service`, предназначенным для воспроизведения фоновой музыки.

Сервис создаёт `MediaPlayer`, загружает ресурс `soundtrack` и включает зацикленное воспроизведение.

Инфраструктура фоновой музыки присутствует в проекте, однако запуск сервиса из основных экранов в текущей версии закомментирован.

## Терминальный интерфейс

Визуальная концепция приложения построена вокруг имитации командной строки.

Сообщения используют следующие префиксы:

```text
app>...
user>...
```

Например:

```text
app>list of commands is available with the 'help' command
app>waiting for input

user>help

app>commands:
run 'name_event' - deploy action on chosen event
clear 'name_event' - clear saves on chosen event
app>waiting for commands
```

Таким образом, терминал является основным способом взаимодействия с игрой.

## Звуковое сопровождение

В проекте используются несколько аудиоресурсов:

* `dev_sound`
* `chapter_selected_sound`
* `soundtrack`

Для воспроизведения используется Android `MediaPlayer`.

Короткие звуковые эффекты используются в главном меню и при выборе глав.

`AmbientMediaPlayer` предназначен для постоянного воспроизведения фонового саундтрека.

* появления элементов главного меню

## Архитектура

Приложение представляет собой небольшой Android-проект, построенный вокруг нескольких Activity.

Основной поток выглядит следующим образом:

```text
MenuActivity
    |
    +-- ChaptersActivity
    |       |
    |       +-- Терминал
    |       +-- Обработчик команд
    |       +-- Выбор глав
    |
    +-- ConfigActivity
    |
    +-- InfoActivity
    |
    +-- AmbientMediaPlayer
```

Логика обработки команд реализована непосредственно в `ChaptersActivity`.

Названия событий и текстовые сообщения терминала вынесены в Android String Resources.
